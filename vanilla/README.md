# StructNova Designs — Vanilla HTML/JS/CSS + Tailwind

Multi-page vanilla rewrite of the React app. No frameworks. Auth + DB via Supabase.

## Setup

```bash
cd vanilla
npm install
npm run dev
```

Opens Tailwind CLI in watch mode and serves `public/` on `http://localhost:5173`.

Production build:

```bash
npm run build
# then host public/ on any static server (Vercel, Netlify, S3, GitHub Pages)
```

## Deployment

- Deploy `public/` as-is (static hosting).
- **Vercel:** set root to `vanilla/`, build command `npm run build`, output directory `public`.
- Supabase redirect URLs must include the deployed origin (Auth → URL Configuration).
